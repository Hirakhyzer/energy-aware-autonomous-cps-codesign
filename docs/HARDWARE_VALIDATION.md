# Optional future physical validation (not required for v0.3)

ECO-CPS v0.3 is a simulation-only research milestone. No hardware purchase, physical robot, embedded board, power meter, or hardware-in-the-loop experiment is needed to reproduce its results.

This document is retained only as a possible future extension if suitable equipment becomes available. Any future physical study would need calibrated current/voltage measurements, synchronized timestamps, processor and sensor power characterization, motor load measurements, and explicit model-to-measurement validation. Until then, every reported joule is a synthetic model output, not measured consumption.
